# 🚀 NEXUS - Advanced Support & Control System

NEXUS is a lightweight but powerful **Support Ticket System + Web Dashboard + API + Plugin System** built with Python and Flask.

---

## 🔥 Features

- 🎫 Ticket Management System
- 🌐 Web Dashboard (Flask)
- 🔌 REST API (JSON)
- 👤 Login System (Admin Panel)
- 📜 Audit Log System
- 📧 Email Notification System
- 🧩 Plugin System
- 🧠 Modular Architecture
